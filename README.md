## California CDL Class A Study App

**Open the app:** https://slimeshadie.github.io/CDL-Training/

Free study app for the California Class A CDL knowledge tests (General Knowledge, Air Brakes, Combination) and the HazMat, Tanker and Doubles/Triples endorsements, plus pre-trip and skills test prep.

- 2,681 practice questions, each with a quick answer, a full explanation and an Evidence section quoting the California Commercial Driver Handbook (DL 650 / DL 650 X), 49 CFR or the California Vehicle Code
- Flashcards with spaced repetition (including HazMat placard and Do Not Load cards), timed practice tests, mixed practice, confidence ratings, progress stats
- Audio pre-trip walkthrough of every DL 650 inspection item with self-scoring, and a placard / hazard class / Do Not Load picture drill
- Readiness for each test (General Knowledge, Air Brakes, Combination, HazMat, Tanker, Doubles/Triples), showing "Ready to book" at 80+
- Study tools: a mistake journal (tag why you missed a question, then drill by reason), pretest mode with pretest vs. post-test scores, two-step hints, an optional "explain it in your own words" box, and practice test history charts with the 80% pass line
- Real test prep: California CDL test formats with official sources, DMV-format practice exams (question count, misses allowed, 3 answer choices, handbook topic weights), skills test guide (modernized vehicle inspection, basic control exercises, road test rules), CLP rules and restriction codes, California size and weight limits, and the CDL test sites
- Worked examples with calculators (following and stopping distance, axle weights and the bridge table, kingpin-to-rear-axle, air brake numbers), ordering, matching, fill-in and scenario exercises, an audio playlist for hands-free review, and read-aloud study guides
- English language proficiency questions and a Reference section (49 CFR 391.11(b)(2), FMCSA roadside policy, California DMV 2026 rules)
- More like this (press L) on every question, flashcard, guide section, diagram and test review: similar questions, related flashcards, guide facts, diagrams, worked examples, exercises and glossary terms, with one-tap practice, flashcards or a mini test on that topic
- Today’s review on the Start page (spaced repetition for questions and flashcards, daily goal, streak), a study session builder, a topic mastery map, notes on any question or guide with search, plain-language summaries and key takeaways on each guide, printable one-page summaries, and end-of-session recaps
- Keyboard shortcuts you can change or turn off (press ? for the list): answer with 1–4 or A–D, N/P or arrows for next and previous, X skip, H hint, E explanation, V evidence, F flag, R read aloud, L more like this, M then 1–5 mistake reason, G then a letter to jump to any tab, Ctrl/Cmd+K command palette, auto-advance after a correct answer; flashcard swipe and optional vibration
- A "Report a problem" link on every question that opens a prefilled GitHub issue
- Works offline after the first visit and can be installed to your home screen
- Accessibility settings (button in the header or Alt+Shift+A): text size, built-in Atkinson Hyperlegible and OpenDyslexic fonts (SIL Open Font License, see [fonts/](fonts/)), line height, letter and word spacing, line width, color-blind-safe mode, system/light/dark theme, high contrast, reduced motion, 1.5×/2×/untimed tests, larger tap targets, strong focus outline, focus mode, reading ruler, read-aloud voice, speed and pitch with captions and word highlighting, and screen-reader announcements

**Android app (test build):** [downloads/ca-cdl-study.apk](downloads/ca-cdl-study.apk) – version 17, debug-signed. It installs over versions 12 to 16 and keeps your progress. If you have an older test build that will not update, export your progress (My stats → export), uninstall it, then install this one.

Study aid only. Always check the current DMV handbook and official rules before your test. See [README-DEPLOY.md](README-DEPLOY.md) for hosting notes.
